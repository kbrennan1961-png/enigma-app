Enigma Machine

Interactive encrypt / decrypt — runs entirely in your browser (no server). Based on the NSA enigma-simulator. Encryption is symmetric: same settings decrypt.

Only a–z / A–Z and spaces are allowed (spaces are stripped by the machine).
Standalone client-side build — embed this single HTML file anywhere (blog post, iframe, static host). Source: github.com/NationalSecurityAgency/enigma-simulator
